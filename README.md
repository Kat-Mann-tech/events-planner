# Event Planner

A React and Vite application that allows users to create, manage and organise events.

## Features

- User registration
- User login and logout
- Dashboard displaying today's and upcoming events
- Add new events
- Edit existing events
- Delete events
- Help page with user guidance
- Responsive design for desktop and mobile devices
- Context API used for user and event state management
- Data stored using local storage

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Context API
- Local Storage
- Git

## Installation

Open a terminal and navigate to the project folder.

Run:
npm install

## Running the Application

Start the development server by running:
npm run dev

Then open the local URL displayed in the terminal.

## Project Structure

- pages: application pages
- components: reusable components
- contexts: Context API providers
- CSS: styling files
